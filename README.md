# SALAKNI DZ — الإصدار 2.0.0

تطبيق المساعدة على الطرقات: **واجهة ويب** + **قاعدة بيانات Supabase** (حسابات، طلبات لحظية، محفظة، تقييم) + **غلاف أندرويد** يُبنى تلقائيًا على GitHub.
التكلفة: **0 دج** على الخطط المجانية (Supabase + GitHub).

```
supabase/schema.sql      قاعدة البيانات والصلاحيات والمنطق (التوزيع، العمولات، التقييم)
web/                     واجهة التطبيق (HTML/CSS/JS بلا أدوات بناء)
android/                 مشروع أندرويد (WebView) يحمّل الواجهة
.github/workflows/       بناء ملف APK تلقائيًا
```

## التشغيل خطوة بخطوة (≈ 20 دقيقة)

### 1) قاعدة البيانات (Supabase)
1. أنشئ حسابًا على supabase.com ثم **New project** (الخطة المجانية). احفظ كلمة مرور قاعدة البيانات.
2. من **Project Settings ▸ API** انسخ: **Project URL** و **anon public key**. (لا تستعمل أبدًا مفتاح `service_role` في التطبيق.)
3. من **SQL Editor ▸ New query**: الصق محتوى `supabase/schema.sql` كاملًا ثم **Run**. يجب أن تظهر «Success».
4. من **Authentication ▸ Sign In / Providers ▸ Email**: **عطّل** خيار **Confirm email** (مطلوب لأن الدخول برقم الهاتف دون بريد حقيقي).

### 2) GitHub (بناء الـAPK)
1. أنشئ مستودعًا **خاصًا (Private)** وارفع إليه كل الملفات مع الحفاظ على المجلدات.
   - إن لم يُرفع مجلد `.github` عبر السحب والإفلات: **Add file ▸ Create new file** واكتب في الاسم `.github/workflows/build-apk.yml` والصق محتواه.
2. **Settings ▸ Secrets and variables ▸ Actions ▸ New repository secret** وأضف سرّين:
   - `SUPABASE_URL` = عنوان المشروع
   - `SUPABASE_ANON_KEY` = مفتاح anon
3. تبويب **Actions ▸ Build APK ▸ Run workflow**. بعد دقائق نزّل الملف من **Artifacts ▸ salakni-dz-debug-apk**، فيه `app-debug.apk`.
4. ثبّته على هاتفين (يلزم السماح بالتثبيت من مصدر غير معروف).

### 3) الاختبار بين هاتفين
1. هاتف 1: أنشئ حساب **قاطر** (تخصص سيارات)، واضغط «تحديد موقعي الحقيقي» وأنت في مكانك.
2. هاتف 2: أنشئ حساب **سائق**؛ ستظهر خريطة بموقعك والقاطر في القائمة. اطلب «قطر السيارات ▸ أقرب ورشة».
3. هاتف 1: يصله إشعار لحظي؛ افتح «الطلبات الواردة» ▸ **قبول**. هاتف 2 يصله إشعار القبول مع رقم المقدّم.
4. أنهِ الطلب ثم قيّم. جرّب المحفظة من حساب مقدّم الخدمة (تعبئة تجريبية +1000 دج).

> لتجربة التطبيق في المتصفح قبل الـAPK: ضع المفتاحين في `web/js/config.js` وشغّل `python3 -m http.server -d web 8000` ثم افتح `http://localhost:8000` (الموقع الجغرافي يعمل على localhost).

## ما الذي أُصلح مقارنة بالإصدار 1
- **الخلل الرئيسي:** موقع مقدّم الخدمة وحالته «مشغول» صارا في سجل واحد، فتظهر القائمة والخريطة ويصل التوزيع فعلًا.
- **بيانات حقيقية بين الأجهزة** (قاعدة بيانات) بدل التخزين المحلي.
- **أمان:** كلمات المرور تُدار عبر Supabase Auth (مُجزَّأة)، والعمولات والتوزيع على الخادم، والمستخدم لا يرى إلا بياناته (RLS).
- **المحفظة:** سجل حركات لا يُعدَّل من التطبيق.
- **التسعير التلقائي يعمل:** تُحوَّل الولاية/البلدية إلى إحداثيات (OpenStreetMap) فتُحسب المسافة (×1.4) والسعر (105 دج/كم من 100 كم).
- **تدفقات كانت ناقصة:** إشعار السائق عند القبول، ظهور التقييم بعد الإنجاز، زر «طلبك الحالي».

## حدود معروفة (عدّلها قبل الإطلاق الفعلي)
- **الخطة المجانية** توقف المشروع بعد 7 أيام بلا نشاط (يُستأنف بنقرة) وسعتها محدودة: مناسبة للعرض التجريبي لا للإطلاق.
- **الدخول برقم الهاتف** يعتمد بريدًا وهميًا `الرقم@phone.salakni.dz`: لا يوجد «نسيت كلمة المرور». للتحقق عبر SMS يلزم مزوّد مدفوع.
- **التعبئة التجريبية:** عطّلها بعد ربط دفع حقيقي: `update public.app_config set value='false' where key='demo_topup';` وضع `DEMO_TOPUP: false` في `config.js`.
- **الـAPK debug** للتجربة. للنشر على Google Play يلزم توقيع release (مفتاح خاص يُحفظ في GitHub Secrets، لا في المستودع).
- التوزيع حاليًا بترتيب عشوائي متساوي الأوزان؛ وتخصص «دراجات نارية» يُسجَّل لكنه لا يُستعمل بعد في التصفية.
- أضف قبل الإطلاق: حدّ لعدد الطلبات لكل مستخدم، نسخًا احتياطيًا، وسياسة خصوصية قانونية.

## استكشاف الأخطاء
| الرسالة | السبب والحل |
|---|---|
| «التطبيق غير موصول بالخادم» | السرّان غير مضبوطين أو لم يُعد بناء الـAPK بعد إضافتهما. |
| «فعّل … Confirm email» | لم تُعطَّل تأكيد البريد في Supabase (الخطوة 1-4). |
| «الرقم مسجّل من قبل» | الهاتف مستعمل. |
| الخريطة فارغة والقائمة فارغة | لا يوجد مقدّم خدمة ضمن 50 كم، أو لم يُسجَّل موقع حقيقي لمقدّم الخدمة. |
| خطأ عند تشغيل SQL | أعد تشغيل الملف على مشروع جديد، وأرسل لي نص الخطأ حرفيًا. |
